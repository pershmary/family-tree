# Семейное древо

Статический сайт на JavaScript и Vite, без базы данных и внешних сервисов.

## Запуск

Нужен Node.js 20.19+ или 22.12+ (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

`npm run build` создаёт статический сайт в `dist`. `npm run preview` запускает проверку сборки.

## Данные

Каждый человек хранится в `public/people/<id>.json`. Список идентификаторов — `public/people/index.json`.

- `id`: уникальный идентификатор.
- `name`: ФИО.
- `birthDate`: дата ISO `YYYY-MM-DD` или `null`, если неизвестна.
- `birthYear`: известный год рождения, если день и месяц неизвестны; в этом случае `birthDate` остаётся `null`.
- `deathDate`: дата ISO или `null` для живого человека либо неизвестной даты смерти.
- `photo`: путь к миниатюре для древа и списка родственников, например `/photos/thumbnails/maria.webp`, или `null` для заглушки.
- `photoFull`: путь к крупному фото, например `/photos/full/maria.jpg`, или `null`. Предназначен для отдельной карточки человека; древо этот файл не загружает.
- `parents`: идентификаторы родителей.
- `spouses`: идентификаторы супругов.
- `deceased`: `true`, если человек умер, но полная дата смерти неизвестна.
- `deathYear`: известный год смерти при неизвестных дне и месяце.
- `notes`: примечания к неполным сведениям.

Родители задаются у ребёнка, потомки и сиблинги вычисляются автоматически. Сиблинги — люди хотя бы с одним общим родителем. Предки и потомки показаны на всех известных уровнях. Супруги показаны для ключевого лица; браки видимых людей отмечаются горизонтальными линиями. Клик меняет ключевое лицо, ссылка «Семейный архив» открывает начальное древо Марии.

По умолчанию выбран `maria` — Першина Мария Сергеевна. Внесены 37 человек и связи из предоставленной схемы. Неизвестные даты и отчества не дополнены предположениями. Для Елены Самсоновны известен только год смерти — 2009. Для людей без загруженных фотографий используются заглушки.

Фотографии хранятся в двух папках: `public/photos/thumbnails/` — квадратные миниатюры WebP до 144 × 144 px (для показа 72 × 72 px на экранах с двойной плотностью); `public/photos/full/` — исходные фотографии без изменения. Маленькие исходники не увеличиваются. При добавлении фото положите оригинал в `full`, подготовьте миниатюру в `thumbnails` и укажите оба пути в JSON человека. Древо и выбор родственника используют только `photo`. Когда появится отдельная карточка человека, назначайте `photoFull` источником изображения только после её открытия; не добавляйте предзагрузку оригиналов в древо.

Линия к детям начинается в середине линии между родителями. Для каждого набора родителей строится отдельная ветвь. Если известен один родитель, рядом с ним автоматически появляется пустая карточка второго родителя с заглушкой фотографии; это визуальная карточка, а не вымышленная запись человека. Супруги потомков не добавляются: линии к внукам и следующим поколениям идут от карточки прямого потомка.

Правила показа: раскрываются прямые предки выбранного человека, его сиблинги, супруги, собственные потомки. Потомки супруга от других браков не раскрываются. Супруги потомков также не отображаются. Предки и боковые родственники супруга не раскрываются автоматически. При выборе супруга его собственные предки становятся видимыми. `gender` (`male` / `female`) задаётся явно в файле человека и определяет порядок родителей: отец слева, мать справа. Для нескольких браков общий родитель может повторяться в отдельных парах; это тот же человек, а не отдельная запись.
