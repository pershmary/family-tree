# Семейное древо

Статический сайт на JavaScript и Vite, без базы данных и внешних сервисов.

## Запуск

Нужен Node.js 20.19+ или 22.12+ (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

`npm run build` создаёт статический сайт в `dist`. `npm run preview` запускает проверку сборки.

## Данные

Каждый человек хранится в `public/people/<id>.json`. Список идентификаторов — `public/people/index.json`.

- `id`: уникальный идентификатор.
- `name`: ФИО.
- `birthDate`: дата ISO `YYYY-MM-DD` или `null`, если неизвестна.
- `deathDate`: дата ISO или `null` для живого человека либо неизвестной даты смерти.
- `photo`: путь к фото в public, например `/photos/maria.jpg`, или `null` для заглушки.
- `parents`: идентификаторы родителей.
- `spouses`: идентификаторы супругов.
- `deceased`: `true`, если человек умер, но полная дата смерти неизвестна.
- `deathYear`: известный год смерти при неизвестных дне и месяце.
- `notes`: примечания к неполным сведениям.

Родители задаются у ребёнка, потомки и сиблинги вычисляются автоматически. Сиблинги — люди хотя бы с одним общим родителем. Предки и потомки показаны на всех известных уровнях. Супруги показаны для ключевого лица; браки видимых людей отмечаются горизонтальными линиями. Клик меняет ключевое лицо, ссылка «Семейный архив» открывает начальное древо Марии.

По умолчанию выбран `maria` — Першина Мария Сергеевна. Внесены 37 человек и связи из предоставленной схемы. Неизвестные даты и отчества не дополнены предположениями. Для Елены Самсоновны известен только год смерти — 2009. Фотографии не извлекались из общего скриншота: для качественных портретов нужны отдельные изображения, пока используются заглушки.

Линия к детям начинается в середине линии между родителями. Для каждого набора родителей строится отдельная ветвь. Если известен один родитель, рядом с ним автоматически появляется пустая карточка второго родителя с заглушкой фотографии; это визуальная карточка, а не вымышленная запись человека. Супруги/вторые родители видимых потомков добавляются для отображения семейной связи.

Правила показа: раскрываются прямые предки выбранного человека, его сиблинги, супруги, собственные потомки и потомки супругов. Предки и боковые родственники супруга не раскрываются автоматически. При выборе супруга его собственные предки становятся видимыми. `gender` (`male` / `female`) задаётся явно в файле человека и определяет порядок родителей: отец слева, мать справа. Для нескольких браков общий родитель может повторяться в отдельных парах; это тот же человек, а не отдельная запись.
